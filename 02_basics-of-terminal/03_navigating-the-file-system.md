# Navigating the File System
- cd ../
- cd ../
- `cd section-`1&nbsp;➜&nbsp;`(cd TAB)`
- cd ../
- `cd section-1`
- cd ../`section-`2
- cd ../&nbsp;➜&nbsp;`(untill ~)`
- cd ../&nbsp;➜&nbsp;`(untill /)`
- cd ../&nbsp;➜&nbsp;`(still /)` (no error)
- cd ~/

> `~` - home directory  
> `/` - root directory (top level, where all drives shown)  
> `cmd + shift + H` ➜ to open `~` in Mac
